# Dynamic Vehicle Rigging

> Technical Animation • Unreal Engine • Control Rig

*Video coming soon.*

## Overview

I designed and authored a dynamic, pose-driven vehicle Control Rig that makes the character lean naturally in response to the vehicle's speed and angular velocity. The system translates real-time vehicle movement into responsive character posing, keeping the rider visually connected to the motion of the vehicle.

I authored the underlying pose-driving systems in C++ for performance and stability. The workflow required no animation assets: artists could pose the character, capture the result directly inside the Control Rig editor, and configure support for new vehicles entirely within Unreal Engine.
